# 受験校プランナー（2027年度入試）

生徒が組・番号・氏名で始め、受験する大学・方式を選んで日程表PDFとカレンダー（.ics）を作るページです。提出はMicrosoft Formsで行い、先生は回答のExcelを教員ページに読み込んで、CSV・生徒ごとのPDF・日別の受験者一覧を出します。サーバーは使いません。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面（生徒・教員とも）。GitHub Pagesに置く |
| `data/master.xlsx` | 大学データ（1行＝1試験）。毎年ここを差し替える |

## データの流れ

- **生徒の入力**：その端末のブラウザに自動保存されます。同じ端末で開けば続きから使えます。
- **提出・バックアップ**：入力内容は「提出コード（JKP1.… で始まる数百文字）」にまとめられます。このコードが提出物とバックアップを兼ねます。
- **先生**：Formsの回答Excel（またはコードを貼った文章）を教員ページに読み込みます。読み込んだデータはその画面にだけあり、閉じると消えます。GitHubにもGoogleドライブにも、生徒のデータは残りません。

## 設置手順

### 1. Microsoft Formsで提出フォームを作る（先生のアカウントだけで可）
1. Formsで新しいフォームを作り、次の4つの質問を「テキスト」で作ります：**組**／**番号**／**氏名**／**提出コード**（提出コードは「長い回答」をオン）。
2. 「設定」で「すべてのユーザーが回答可能」にします（生徒はサインイン不要になります）。
3. 「…」メニューの「事前入力済みリンクを取得」を開き、組に `CLASS`、番号に `NO`、氏名に `NAME`、提出コードに `CODE` と入れて、リンクを作成・コピーします。
4. `index.html` の上の方にある `CONFIG` の `FORM_URL: ''` の中に、コピーしたURLを貼ります。

> `FORM_URL` が空欄のときは、提出ボタンが「提出用コードをコピー」になります。Classroomのコメントやメールに貼ってもらう運用もできます。

### 2. GitHub Pagesに置く
1. 必要なら `CONFIG` の `SCHOOL`（学校名）と `CLASSES`（組の一覧）も書き換えます。
2. GitHubのリポジトリに `index.html` と `data/master.xlsx` をアップロードします（フォルダ構成はこのまま）。
3. 「Settings → Pages」で公開すると、`https://（ユーザー名）.github.io/（リポジトリ名）/` が生徒用のURLになります。

## 使い方

### 生徒
1. 組・番号・氏名を入れて「はじめる」。iPadは共有ボタンから「ホーム画面に追加」して開くと、入力が消えにくくなります（Safariは長く開かないサイトのデータを消すことがあるため）。
2. 受験校を、「大学から追加」「カレンダーから追加」「共テ利用」のいずれかで追加します。各入試に受験科目と配点、ボーダー（偏差値・共テ得点率）が出ます。「自分の受験科目で絞り込む」を押して科目を選ぶと、その科目だけで受けられる方式に絞れます（選んだ科目は進路データにも保存）。大学の画面では「並べ替え」で試験日順・偏差値順・共テ得点率順・科目数の少ない順・受験科目でまとめる、に切り替えられます。カレンダーは分野・大学群で絞り込むと、各日に試験のある大学が略記で並びます。大学名を押すと、その日の学部・学科・方式が出ます。進路データ（英検・外部試験・共テ目標点・模試・第1志望・先生へのメモ）も入力します。
3. 「先生に提出」を押すとフォームが入力済みで開くので、フォームの「送信」を押します。内容を変えたら、もう一度提出します（画面に「提出後に変更あり」と出ます）。
4. 「カレンダーをPDFに（横向き）」で1か月1ページの受験カレンダー、「一覧表＋カレンダーをPDFに」で一覧表付きを印刷（PDF保存）します。「カレンダーに追加」で .ics を書き出します。受験予定タブは「リスト／カレンダー」で表示を切り替えられます。
5. 端末を変えたときや入力が消えたときは、最初の画面の「復元コードから再開」に、控えておいたコードを貼ります。

### 先生
1. ログイン画面右下の「教員の方はこちら」を開きます。
2. **Microsoft 365 連携を設定している場合**：「Formsから最新を読み込む」を押すと、Formsの回答Excelから全員分の最新を読み込みます（最初だけMicrosoftのサインインと、回答Excelの選択）。開いている間は5分ごとに自動で更新します。ほかの年度の提出は自動で除きます。
   **設定していない場合**：「Excelを選ぶ」でFormsの回答Excelを選びます。Chrome・Edgeでは選んだExcelをそのパソコンで覚えるので、次からは「最新を読み込む」を押すだけです。OneDriveで同期しているフォルダのExcelを選べば、いつも最新の回答が読めます（開いている間は5分ごとに読み直し）。メールやClassroomの画面をまとめてコピーして貼り付けてもかまいません。中からコードだけを拾い、同じ生徒は最新の提出を使います。
3. 生徒一覧・詳細の確認、受験校一覧CSV（1行1受験）・生徒一覧CSV（1行1生徒）・日別受験者CSV、選んだ生徒の受験校一覧PDF（1人1枚）が使えます。

## 大学データ（data/master.xlsx）

「入試日程」シートの列：ID／区分／大学／学部／学科／方式／種別（一般・共テ併用・共テ利用・国公立）／試験日／出願開始／出願締切／合格発表／手続締切／ボーダー偏差値／共テボーダー／共テ科目／共テ配点／個別科目／個別配点／科目要件／備考／確度／出典。

- **受験科目・配点**：Kei-Netの科目・配点データ（2027年度入試用）から、全4,538行に入れています。〔 〕はどれか選ぶ科目、〈 〉は教科をまたいで選ぶ枠です。「科目要件」は絞り込み用の記号です（書き方は「記入ルール」シート）。
- **ボーダー**：「ボーダー偏差値」は河合塾のボーダー帯（一般方式）。「共テボーダー」は得点率（%）を数字で入れる欄で、今は空欄です。業者のボーダー表が届いたら入れてください。

- **収録大学**：早慶上理・GMARCH・成成明学獨國武・4工大・日東駒専・薬学部（星薬・北里・東京薬科・明治薬科・昭和薬科・東邦）・看護（日赤看護・聖路加・慈恵・順天堂・東京医療保健）・近隣国公立13校。約4,500行。
- **確度**：
  - `2027確定`：2027年度の公表値
  - `目安`：国公立の共通日程。合格発表は空欄
  - `前年参考`：2027年度が未発表のため前年の日程（専修の後期など）
  - `要確認`：発表日が学部ごとに異なるなど、要項で確認が必要
  
  11月以降に各大学の要項が出たら、確度の低い行から直してください。
- 「大学」シートの **略称** が、カレンダーとPDFに出る大学名です（例：青山学院→青学）。「入試日程」シートに **分野** 列（理工・情報／医療・看護／薬学／国際・語学／経済・経営／法・政治／文・教育・心理）を足すと、カレンダーの分野分けをその値で上書きできます。空欄なら学部・学科名から自動で判定します。
- 提出コードには入試の **ID** が入っています。年度の途中で直すときは、既存の行のIDを変えないでください（新しい行はIDを空欄にすれば自動で振られます）。

## 次年度の更新
1. 教員ページ「大学データ」で、Kei-Netの入試日一覧xlsxを読み込み、「変換結果をExcelで保存」。出願・発表・手続日を入れ、「設定」シートの年度・共通テスト日・データ更新日を書き換えます。
2. GitHubの `data/master.xlsx` を差し替えます。
3. Formsの回答を「すべての回答を削除」で空にします。同じフォームを使い続ければ、`FORM_URL` の変更は不要です。

## AI相談（教員ページ）
教員ページの「AI相談」タブで、生徒ごとの「生徒の情報をコピー」を押してClaudeのチャットに貼り付けます。コピーされるのは情報だけです（受験予定・共テ目標と模試・英検・第1志望・本人の不安・日程の注意点）。氏名・組・番号も入ります（入れたくないときはチェックで外せます）。
指示のほうは、同じタブの「共通の指示のテンプレート」を学校の方針に合わせて書き換えて使います。Claudeで「プロジェクト」を作り、この指示をプロジェクトの指示欄に入れておけば、あとは生徒の情報を貼るだけで済みます。

## 教員ページ
- 生徒用ページ右下の「教員の方はこちら」から入ります。パスワードの初期値は **takumi** です（「システム設定」で変更できます）。
- 静的なページなので、パスワードは「見られたくない人に開かせない」ための簡易的なものです。生徒の提出データはページに保存されておらず、先生が読み込んだときだけ画面に出ます。

## システム設定（教員ページ）
- **基本設定**：学校名・組の選択肢・Microsoft Formsの事前入力リンク・教員パスワード。「設定を保存して公開」で `data/config.json` に保存され、全員のページに反映されます。
- **公開の合鍵**：「公開する」「設定を保存して公開」を使うために、パソコンごとに1回、合鍵（GitHubのアクセストークン）を登録します。作り方は画面に書いてあります。合鍵はそのブラウザにだけ保存されます。

## Microsoft 365 連携（Formsの回答を自動で読み込む）
- 学校のMicrosoft 365に「アプリの登録」を1つ作り、2つのID（アプリケーションID・テナントID）をシステム設定に入れます。手順はシステム設定の画面にあります。登録は学校に属するので、担当が変わっても消えません。
- フォームはTeamsの学年団・進路部などのグループの持ち物にしておくと、担当が変わっても引き継ぎが要りません。回答Excelは、Formsの「回答」→「Excelで開く」で作られる、回答が自動でたまるExcelです。
- 回答Excelを読めるのは、そのExcelを持っているか共有されている先生だけです。選んだExcelは各パソコンのブラウザに保存されます（ページには載りません）。
- 提出コードには年度が入っているので、回答を消さずに次年度も同じフォームを使えます。

## 年次更新（担当が変わっても同じ手順）
1. 「システム設定」→「更新用Excelをダウンロード」で `master.xlsx` を取得します。
2. 外部AI（ClaudeやChatGPTなど）に、Excel内の「AIへの依頼文」と一緒に渡して更新してもらいます。手で直してもかまいません。
3. 「更新したExcelをチェック」に入れて、エラーがあれば直します。「この端末で試しに表示」で画面も確認できます。
4. 「このExcelを公開する」を押します。1〜2分で全員のページに反映されます。
5. Formsの回答は消さなくても、ほかの年度の分は自動で除かれます（回答が多くなって重いときだけ消してください）。必要に応じて基本設定も見直します。

`tools/` には、今年度のデータを作ったプログラムが入っています（Kei-Netのファイルからまとめて作り直す場合に使います）。

## 引き継ぎ（担当が変わるとき）
- 入試日程の更新と公開は、合鍵が登録されたパソコンがあれば誰でもできます（教員ページ →「システム設定」→ ①〜③）。
- 合鍵を新しく作れるのは、GitHubの組織 **nu1school** のメンバーだけです。後任の先生がGitHubのアカウントを作り、今の管理者が組織に招待（Owner）すれば、後任が自分で合鍵を作れます。
- 合鍵の有効期限は最長1年です。期限が切れたら、組織のメンバーが作り直して貼り直してください。
