# 年次更新手順（Claudeに頼むとき用）

毎年10月ごろ、Claudeのチャットで次のように頼めば更新できます。

> 受験校プランナー（nu1school/jukenko）の大学データを2028年度入試用に更新して。Kei-Netのファイルを添付します。

## 先生が用意するもの
1. Kei-Net「入試日一覧」のExcel（大学群ごとにダウンロードしたもの。今年と同じ範囲）
2. Kei-Net「科目・配点データ」のExcel（私立・国公立の2ファイル）

## Claudeがやること
1. `tools/parse_keinet.py` でKei-Netのファイルを読み込む。
2. `tools/rules.py` の日付（出願・発表・手続）を、その年の情報に調べ直す。
   - 主な情報源：Kei-Net「大学からのお知らせ（一般選抜の特徴）」`search.keinet.ne.jp/{大学コード}/topics/12`、ベネッセ マナビジョン「合格発表日」、各大学の入試ガイド。
   - 大学コードは科目・配点データの「１０桁コード」の先頭4桁。
   - 調べきれない日付は空欄にして、確度を「要確認」「前年参考」にする。
3. `tools/build_master.py` で `data/master.xlsx` を作り直す（年度・共通テスト日・データ更新日は rules.py と build_master.py の「設定」部分を更新）。
4. ブラウザで動作確認して、GitHubにpushする。

## 先生がやること（Claudeとは別に）
- Microsoft Formsの回答を「すべての回答を削除」で空にする（フォームは使い回し）。
