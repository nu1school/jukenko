# 年次更新手順

## ふつうの更新（だれでもできる）
1. 教員ページ「システム設定」タブの「更新用Excelをダウンロード」でExcelを取得する。
2. Excelの「AIへの依頼文」シートの文章とExcelを外部AI（Claude・ChatGPTなど）に渡して更新してもらう。人が手で直してもよい。列の書き方は「記入ルール」シートにある。
3. 教員ページ「システム設定」タブの「更新したExcelをチェック」で確認する。エラーがなくなるまで直す。
4. 「このExcelを公開する」を押す（GitHubとの接続が未設定なら、GitHub の data フォルダに master.xlsx としてアップロードしてもよい）。
5. 新年度なら Microsoft Forms の回答を空にする。
